# subgrad — Frontend

React + Vite. See the [root README](../README.md) for what this actually is.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
npm run lint
```

Guest mode (no backend needed) covers most of the labs. Set `VITE_*` env vars
per `.env.example` to hit a local or deployed backend for the Socratic tutor.
